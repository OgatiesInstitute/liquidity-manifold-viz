# liquidity-manifold-viz
Liquidity Manifold Visualization

This repository provides the technical implementation for "Reality as a Stochastic Film" (Pattern Recognition and English Learning Vol.3).
It transforms abstract financial manifolds into an observable, geometric experience using three.js and Python.
It visualizes the curvature singularity of the liquidity surface, where the fault line is detected by the spike in $W_2$ (Wasserstein-2) distance.

Technical Supplement: Running the Simulation
To visualize the liquidity manifold as a "Stochastic Film" on your own machine, follow these steps:

1. Environment Setup
Ensure you have Python 3.8+ installed. Install the necessary mathematical and networking libraries via terminal:

Bash
pip install torch numpy scipy websockets
2. Launching the Engine (Backend)
Navigate to your project directory and start the SDE solver. This script generates the real-time score-based liquidity reconstruction:

Bash
python backend/main.py
You should see a message: WebSocket server started on ws://localhost:8765

3. Projecting the Vision (Frontend)
Since modern browsers restrict local file access for security, you must serve the frontend via a local HTTP server. Open a new terminal window and run:

Bash
python -m http.server 8000
Then, open your browser and navigate to:

http://localhost:8000

Why Localhost?
The simulation utilizes a Local WebSocket Bridge. By running the computation on your own hardware (localhost), you ensure zero-latency synchronization between the stochastic differential equations and the 3D WebGL rendering. This creates a truly sovereign "Stochastic Film" where the reality you observe is generated by the very machine you hold.
